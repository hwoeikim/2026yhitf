# 엘리트 초청 신청서 (아임웹 입력폼) 항목 — 회원만 작성 가능

## 영문 (en /elite)
1. Full name (as in passport) — 짧은 텍스트, 필수
2. Gender — 선택(Male / Female), 필수
3. Nationality — 짧은 텍스트, 필수
4. Date of birth — 날짜, 필수
5. Email — 이메일, 필수
6. Mobile (with country code, e.g. +1 210 555 1234) — 짧은 텍스트, 필수
7. ITRA profile link — 짧은 텍스트(URL), 필수
8. Current ITRA Performance Index — 숫자, 필수
9. Preferred race — 선택(5KM RUNNING (Sat) / 10KM RUNNING (Sat) / 10KM RUNNING (Sun) / 15KM TRAIL RUN (Sat) / 28KM TRAIL RUN (Sun)), 필수
10. Already registered? If yes, your order number — 짧은 텍스트, 선택
11. Message to the organizer — 긴 텍스트, 선택
12. Consent to collection and use of personal information — 동의 체크, 필수

## 국문 (/elite)
1. 성함 — 필수
2. 성별 — 선택(남 / 여), 필수
3. 생년월일 — 필수
4. 휴대폰 번호 — 필수
5. 이메일 — 필수
6. ITRA 프로필 링크 — 필수
7. 현재 ITRA 점수 — 숫자, 필수
8. 희망 종목 — 선택(5KM RUNNING 12.12 토 / 10KM RUNNING 12.12 토 / 10KM RUNNING 12.13 일 / 15KM TRAIL RUN 12.12 토 / 28KM TRAIL RUN 12.13 일), 필수
9. 이미 참가신청을 하셨다면 주문번호 — 선택
10. 전달 사항 — 선택
11. 개인정보 수집·이용 동의 — 필수
