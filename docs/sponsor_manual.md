## 0. 먼저 알아둘 것
- 실제로 화면에 나가는 건 아임웹 코드 위젯이다. 저장소 사본(main/*.html 등)은 예전 상태일 수 있다. 작업 전에 위젯 코드를 먼저 열어 현재 목록을 확인한다.

- 위젯 코드 수정 → 저장 → 게시까지 해야 사이트에 반영된다. 게시 후 실제 사이트에서 PC·모바일 둘 다 확인한다.

## 2. 로고 추가
### 목록 한 줄 형식
```
{ g:'협찬', name:'샘트리', src:'이미지 주소', ratio:3.10, size:1 },
```
- `g`: 분류. '주최·주관' / '후원' / '협찬' 중 하나.
- `name`: 국문 이름. 영문 사이트는 `YH_NAME_EN` 표에 `'샘트리':'Samtree'`처럼 영문 이름을 같이 넣는다.
- `src`: 아임웹에 올린 이미지 주소(cdn.imweb.me) 또는 SVG.
- `ratio`: 로고 가로÷세로 (여백을 잘라낸 기준). 예: 가로 620px, 세로 200px이면 3.10.
- `size`: 기본 1. 크기는 자동으로 맞춰지므로(가로로 긴 로고는 낮게, 정사각에 가까운 로고는 높게) 보통 손대지 않는다. 같은 줄의 다른 로고보다 눈에 띄게 크거나 작아 보일 때만 0.8~1.1 사이로 조정한다.

### 로고 파일 고르는 기준
- 협찬사가 준 공식 파일을 쓴다. 다시 그리거나 색을 바꾸지 않는다.
- 버전이 여러 개면 가로형(한 줄) 우선. 가로형이 없을 때만 두 줄(세로형)을 쓴다.
- 흰 배경용 컬러 버전. 흰 글씨 버전은 쓰지 않는다.
- ®·™ 표기는 협찬사가 준 파일에 있으면 그대로 둔다. 없는 파일에 붙이지 않는다.
- 형식: SVG가 가장 좋고, 아니면 투명 배경 PNG(높이 200px 이상).
- 파일 주변 여백은 잘라낸다. 여백이 남아 있으면 로고가 작아 보인다.

### 순서
- 새 협찬사는 '협찬' 줄의 맨 뒤에 넣는다. (예: 10/28 샘트리 → 네이처밸리 뒤, 10/31 아미노리젠 → 맨 뒤)
- 현재 순서가 위젯마다 조금 다르다: 국문 메인은 KEEN·진안홍삼·네이처밸리·샘트리·아미노리젠, /invited와 영문 메인 목록은 진안홍삼이 샘트리 뒤에 있다. 새 협찬사는 각 목록의 맨 뒤에 붙인다.
- 본부에서 순서를 따로 정해주면 그 순서를 따른다.
- `#yh-sp`, `#yh-roll`, `#yh-inv` 세 곳의 순서를 똑같이 맞춘다.

## 3. 키트 물품 추가
원본: 저장소 `medal/v2/page.html`(국문), `medal/v2/page_en.html`(영문). 빌드 방법은 `rewards/README.md`.

물품 하나를 추가하면 아래 네 군데를 같이 고친다.
1. **구성품 표 (`.yx-tbl`)**: 구성품 / 수량. "전 종목 공통" 묶음과 "트레일런만" 묶음 중 맞는 곳에 넣는다.
2. **라인 일러스트 목록 (`.yx-specs`)**: 선 일러스트 `l_이름.svg`. 기존 일러스트처럼 검은 단색 선만 쓰고 채색하지 않는다. 선 굵기도 기존 것과 같게 맞춘다.
3. **연출 사진 (`.yx-lb`)**: `e_이름.webp`. 가로 1600px 안팎, webp로 저장한다.
4. **번호**: 01부터 차례로 다시 매긴다. 표·일러스트·사진의 번호가 모두 같아야 한다. 완주 자켓(트레일런만 해당)은 항상 맨 끝 번호다.

- 같은 협찬사의 로고도 1번 로고 위치에 함께 추가한다.
- "10만원 상당" 문구: 본부 확인 없이 바꾸지 않는다. 물품이 늘어도 그대로 두고, 금액을 바꿔야 할 것 같으면 메인방에 먼저 말한다.
- 반영 위치: 국문 메인, 국문 /rewards, 영문 메인, 영문 /rewards 네 곳.
- 이미지를 바꿨으면 `sh rewards/sync_assets.sh` → 나온 SHA로 `python3 rewards/build.py <SHA> main|rewards` (영문은 build_en.py).

## 3-1. 실제 작업 순서 (10/31 아미노리젠 기준)
1. 파일 받기: 로고 SVG, 제품 컷(투명 PNG), 연출 사진. 대회 폴더 `홈페이지\추가\`, `로고\`에 있다.
2. 로고 SVG: 한 파일에 여러 버전이 들어 있으면 하나만 잘라 낸다(아미노리젠은 두 줄 ® 버전, 비율 2.5). `medal/v2/logo_이름.svg`로 저장.
3. 키트: `medal/v2/page.html`, `page_en.html`의 표·일러스트·사진·번호를 고친다. 일러스트 `l_이름.svg`, 사진 `e_이름.webp`(1400×1400, 단색 배경 위 제품 컷).
4. `sh rewards/sync_assets.sh` → 나온 SHA로 `python3 rewards/build.py <SHA> main|rewards|enmain|en` → 커밋·push.
5. 아임웹 위젯 교체: `<div id="yh-rewards">`부터 `setTimeout(hd,800);})();</script></div>`까지만 새 내용으로 바꾼다.
   - 영문 메인 위젯은 같은 위젯 안에 KIA 럭키드로우 코드가 뒤에 붙어 있다. 위젯 전체를 덮어쓰면 KIA가 사라진다.
   - 위젯 코드 줄바꿈이 \r\n인 곳이 있어 문자열 검색 시 주의.
6. 로고 위젯(`#yh-sp`, `#yh-roll`, `#yh-inv`) 6곳에 한 줄씩 추가. 영문 이름표 `YH_NAME_EN`에도 추가.
   - 이름표를 고칠 때 앞뒤 따옴표·쉼표를 꼭 확인. 10/31에 쉼표 하나가 빠져 영문 메인 로고 섹션 두 곳이 약 25분간 비어 보였다.
7. 게시 후 국문·영문 메인, /rewards, /invited에서 로고가 보이는지, 키트 표 번호가 맞는지, 모바일 사진 캡션이 겹치지 않는지 확인.

```
- 10/31 15:20 협찬 로고 추가: 샘트리 (KR·EN 메인 로고 섹션·로고 띠·/invited) — 게시·PC/모바일 확인 완료
- 10/31 15:40 키트 물품 추가: 06 샘트리 맛 병아리콩 (표·일러스트·사진, 번호 07~09로 밀림) — KR·EN 메인·/rewards 게시
```
- 무엇을 / 어디에 / 게시했는지 / 확인했는지를 적는다.
- 확인 못 한 것이 있으면 "모바일 미확인"처럼 그대로 적는다.
- 저장소를 고쳤으면 `rewards/README.md` 아래쪽 기록에도 한 줄 남긴다.
